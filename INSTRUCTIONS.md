# Инструкция по запуску и использованию калькулятора курсов криптовалют

## О проекте
**CCPriceConverter** — веб-калькулятор криптовалютных курсов и объёмов обмена, собирающий котировки от 4 провайдеров:
- **DefiLlama** (работает напрямую из браузера без ключей)
- **CoinMarketCap** (требует API-ключ и локальный прокси из-за ограничений CORS)
- **CoinGecko** (работает напрямую, опционален Demo/Pro API-ключ)
- **CoinPaprika** (работает напрямую, опционален Pro API-ключ)

---

## Почему нужен локальный мини-сервер для CoinMarketCap?

Платформа **CoinMarketCap** сознательно блокирует прямые браузерные запросы (отсутствуют CORS-заголовки `Access-Control-Allow-Origin`), защищая приватные ключи пользователей. Если отправить `fetch()` напрямую из браузера на домен `pro-api.coinmarketcap.com`, браузер заблокирует ответ с ошибкой безопасности.

Для решения этой проблемы в проект включен сверхлегкий локальный сервер (доступны версии как на **Node.js**, так и на **Python 3** без единой внешней зависимости). Сервер:
1. Раздает статические файлы сайта (`index.html`, CSS, JS).
2. Проксирует запросы к `https://pro-api.coinmarketcap.com` через локальный эндпоинт `/api/cmc/*` с добавлением всех нужных CORS-заголовков.

## Варианты запуска

### Вариант 1: Запуск через Node.js (Рекомендуемый)

Убедитесь, что установлен Node.js (версии 18+). Внешние пакеты устанавливать **не требуется**.

```bash
# Перейдите в папку проекта:
cd /home/mega/git/CCPriceConverter

# Запустите сервер одной командой:
npm start
# либо:
node server.js
```

Сервер запустится по адресу: **`http://localhost:3000`**

---

### Вариант 2: Запуск через Python 3

Если вам удобнее Python 3, используется стандартная библиотека Python (без `pip install`):

```bash
# Перейдите в папку проекта:
cd /home/mega/git/CCPriceConverter

# Запустите сервер:
python3 server.py
```

Сервер также будет доступен по адресу: **`http://localhost:3000`**

---

### Вариант 3: Запуск на произвольном порту

Если порт 3000 занят, можно передать переменную окружения `PORT`:

```bash
PORT=8080 node server.js
# или
PORT=8080 python3 server.py
```

---

### Вариант 4: Автономный запуск (Pure Static HTML)

Вы также можете открыть файл `index.html` прямо в браузере (через `file:///` или любой статический сервер, например Live Server в VS Code / Antigravity IDE).
- Провайдеры **DefiLlama**, **CoinGecko** и **CoinPaprika** будут работать напрямую через публичный CORS.
- Для **CoinMarketCap** в таком режиме потребуется запущенный локальный прокси либо доступный внешний CORS-прокси (в интерфейсе предусмотрена информативная подсказка при отсутствии прокси).

## Использование интерфейса

1. **Выбор провайдеров**:
   - По умолчанию отмечен провайдер **DefiLlama**.
   - Можно отметить от 1 до 4 провайдеров.
   - Если активен только один чекбокс, он блокируется от снятия (в калькуляторе всегда выбран минимум один источник).
   - При активации CoinMarketCap, CoinGecko или CoinPaprika справа появляется поле ввода API-ключа.
   - Слева от поля ввода отображается индикатор статуса: эмодзи дискеты (`💾`), если ключ сохранён в `localStorage`, либо перечёркнутая дискета, если включен режим без сохранения.
   - Если снять чекбокс провайдера, введенный ключ не стирается, а сохраняется в памяти и кэшируется в `localStorage` (если не включен запрет сохранения).

2. **Ввод данных (Input)**:
   - В колонке **"Продажа"** выберите криптовалюту (BTC, ETH, BCH, ZEC, XMR, XRP) и введите объем продажи.
   - В колонке **"Покупка"** выберите криптовалюту и введите ожидаемый объем покупки.

3. **Расчет**:
   - Нажмите кнопку **"Посчитать"**.
   - Кнопка блокируется на 3 секунды со статусом `"Отправлено"`, предотвращая случайные повторные клики.
   - Запросы уходят **только** по нажатию кнопки.

4. **Отображение результатов (Output)**:
   - Для каждого активного провайдера отрисовывается информационная карточка:
     - Цена за 1 единицу каждой из выбранных валют в USD.
     - Суммарная стоимость объема продажи и покупки в USD.
     - Разница объемов (дельты):
       - Потери $> 20$ USD $\to$ **Красный цвет**.
       - Потери от $0$ до $20$ USD $\to$ **Желтый цвет**.
       - Профит $\to$ **Зеленый цвет** с красной пометкой **`(WTF?)`**.
     - Потери/профит в процентах от среднего арифметического объемов.

5. **Смена языка и темы оформления (в самом верху страницы)**:
   - **Язык интерфейса**: мгновенное переключение между **English** (по умолчанию) и **Русский** (с сохранением выбора в `localStorage` и моментальным переводом всех результатов на экране).
   - **Тема оформления**: выбор между **Light** (светлая), **Dark** (тёмная — по умолчанию) и **System** (системная, автоматически реагирует на настройки ОС).

6. **Управление сохранением API-ключей и приватность**:
   - **Чекбокс «Не сохранять ключи»**: превентивный режим для работы на чужом или общем компьютере. Когда чекбокс активен, вводимые API-ключи остаются исключительно в памяти сессии и не сохраняются в `localStorage`. Слева от полей ввода отображается перечёркнутая дискета.
   - **Кнопка «Стереть ключи»**: позволяет в любой момент стереть все сохранённые API-ключи из `localStorage` браузера и очистить текущие поля ввода.
   - **Интерактивное подтверждение при активации чекбокса**: при включении отметки «Не сохранять», если в `localStorage` уже хранятся ранее сохранённые ключи, появляется всплывающее окно с предложением **«Очистить»** или **«Оставить»** сохранённые ключи.
