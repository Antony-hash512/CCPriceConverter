ℹ️ About the Project

Overview

CCPriceConverter is a browser-based cryptocurrency exchange rate and volume calculator that queries live APIs from 4 providers:

  • 🦙 DefiLlama: Works directly in browser, no API key required.
  • 🔵 CoinMarketCap: Requires an API key and the local proxy due to CORS restrictions.
  • 🦎 CoinGecko: Direct browser calls, optional Demo/Pro API key.
  • 🌶️ CoinPaprika: Direct browser calls, optional Pro API key.

🛡️ Why is a Local Mini-Server Needed for CoinMarketCap?

CORS Proxy

CoinMarketCap intentionally prevents client-side browsers from making direct API calls (missing Access-Control-Allow-Origin headers) to prevent private API keys from being leaked in public frontends. Direct fetch() calls from a browser will always be blocked with a CORS error.

To resolve this without complex infrastructure, the repository includes a zero-dependency mini-server (available in both Node.js and Python 3) that serves the static assets and acts as a reverse CORS proxy for /api/cmc/*.

🚀 Launch Options

Quick Start

Option 1: Run via Node.js (Recommended)

Requires Node.js 18+. No npm packages need to be installed.

cd /home/mega/git/CCPriceConverter
npm start
# or: node server.js

Option 2: Run via Python 3

Uses the standard Python library (no pip packages needed).

cd /home/mega/git/CCPriceConverter
python3 server.py

Option 3: Custom Port

Specify a port via the PORT environment variable:

PORT=8080 node server.js
# or: PORT=8080 python3 server.py

Option 4: Standalone Run (Pure Static HTML)

Open index.html directly via file:/// or any static server. DefiLlama, CoinGecko, and CoinPaprika will work via public CORS, while CoinMarketCap will display an informative hint to start the local proxy.

⚙️ Using the Interface

Step-by-Step
1
Select Providers

DefiLlama is selected by default. You can enable 1 to 4 providers. If only one provider is selected, it cannot be unchecked. Entering API keys for paid providers persists automatically in localStorage even when toggled off.

2
Enter Trade Parameters

In the Sell and Buy columns, pick your desired cryptocurrencies (BTC, ETH, BCH, ZEC, XMR, XRP) and specify the quantities.

3
Click "Calculate"

Requests are sent strictly upon clicking this button. The button locks for 3 seconds with the label "Sent" and a cooldown bar to prevent accidental re-triggers.

4
Analyze Results

Each active provider shows 1-unit rates, total sell/buy volume in USD, and volume difference with color coding: Loss > $20 (Red), Loss $0-$20 (Yellow), and Profit (Green with red WTF? badge).

5
Language & Theme Customization

Use the top preferences bar to switch between English and Russian instantly without losing calculated data, or choose Light, Dark, or System theme.

ℹ️ О проекте

Обзор

CCPriceConverter — веб-калькулятор криптовалютных курсов и объёмов обмена, собирающий котировки от 4 провайдеров в реальном времени:

  • 🦙 DefiLlama: Работает напрямую из браузера без ключей (включён по умолчанию).
  • 🔵 CoinMarketCap: Требует API-ключ и локальный прокси из-за ограничений CORS.
  • 🦎 CoinGecko: Работает напрямую, опционален Demo/Pro API-ключ.
  • 🌶️ CoinPaprika: Работает напрямую, опционален Pro API-ключ.

🛡️ Почему нужен локальный мини-сервер для CoinMarketCap?

CORS Прокси

Платформа CoinMarketCap сознательно блокирует прямые браузерные запросы (отсутствуют CORS-заголовки Access-Control-Allow-Origin), защищая приватные ключи пользователей от утечки на клиенте. Прямой вызов fetch() из браузера на pro-api.coinmarketcap.com блокируется браузером с ошибкой CORS.

Для решения этой проблемы в проект включен сверхлегкий локальный сервер (доступны версии как на Node.js, так и на Python 3 без внешних зависимостей). Сервер раздаёт статику и прозрачно проксирует запросы к /api/cmc/*.

⚙️ Использование интерфейса

Пошагово
1
Выбор провайдеров

По умолчанию активна только DefiLlama. Можно выбрать от 1 до 4 чекбоксов. Если активен только 1 чекбокс, он блокируется от снятия. При скрытии полей API-ключей введённые данные не стираются и сохраняются в localStorage.

2
Ввод параметров сделки

В столбцах Продажа и Покупка укажите криптовалюты (BTC, ETH, BCH, ZEC, XMR, XRP) и желаемые объёмы.

3
Нажатие «Посчитать»

Запросы отправляются исключительно по клику на кнопку. Кнопка блокируется на 3 секунды со статусом «Отправлено» для предотвращения случайных повторных запросов.

4
Анализ результатов

Для каждого активного провайдера выводятся курсы за 1 ед., суммарные стоимости в USD и разница с цветовой градацией: Потери > $20 (Красный), Потери $0-$20 (Жёлтый), Профит (Зелёный с красным WTF?).

5
Настройка языка и темы

В самом верху страницы можно мгновенно переключать язык (English / Русский) и тему оформления (Light, Dark, System) с моментальным обновлением всех карточек.
